[1] 거리 기준점(Reference Distance) 검토
================================================================================

■ 문제 제기
--------------------------------------------------------------------------------
Gpuff 코드(gpuff_plot.cuh)에서 ring별 농도 계산 시 사용하는 거리 기준에 대한
검토가 필요했음. 기존 코드에는 다음과 같은 주석이 있었음:

    // Get ring outer boundary distance (RCAP uses outer boundary)
    float r_inner = (rad_idx == 0) ? 0.0f : SC.ir_distances[rad_idx - 1];
    float r_outer = SC.ir_distances[rad_idx];
    float ring_distance = r_outer;  // Use outer boundary like RCAP

이 주석("RCAP uses outer boundary")의 근거가 RCAP 공식 문서에서 확인된 것인지,
아니면 추정에 의한 것인지 확인이 필요했음.


■ 조사 과정
--------------------------------------------------------------------------------
1. docs/RCAP_matching_analysis.md 문서 검토
   - 147-148번 줄의 수정 이력 확인:
     "2. Ring 중심 거리 → Ring 외경(outer boundary) 거리로 변경"
   - 이는 GPUFF 코드의 수정 이력이며, RCAP 문서에서 직접 확인된 것이 아님

2. 프로젝트 내 RCAP 관련 파일 탐색
   - RCAP 출력 파일(.out) 탐색 시도
   - RCAP 입력 파일(Test.inp 등) 확인
   - RCAP 매뉴얼이나 소스코드에서 직접적인 근거를 찾지 못함

3. 결론
   - "Use outer boundary like RCAP" 주석은 RCAP 공식 문서에서 확인된 것이 아님
   - 이전 개발 과정에서 결과 비교를 통해 outer boundary 사용 시
     RCAP 결과와 더 잘 맞았기 때문에 그렇게 변경한 것으로 추정됨
   - 정확한 확인을 위해서는 RCAP 소스코드나 상세 기술문서 참조 필요


■ 조치 사항
--------------------------------------------------------------------------------
거리 기준을 ring의 중앙값(midpoint)으로 변경하고, 기존 방식은 주석처리하여
나중에 비교할 수 있도록 보존함.

파일: gpuff_plot.cuh
위치: 1460-1468번 줄

[변경 전]
    // Get ring outer boundary distance (RCAP uses outer boundary)
    float r_inner = (rad_idx == 0) ? 0.0f : SC.ir_distances[rad_idx - 1];
    float r_outer = SC.ir_distances[rad_idx];
    float ring_distance = r_outer;  // Use outer boundary like RCAP

[변경 후]
    // Get ring boundaries
    float r_inner = (rad_idx == 0) ? 0.0f : SC.ir_distances[rad_idx - 1];
    float r_outer = SC.ir_distances[rad_idx];

    // Use ring center (midpoint) as reference distance
    float ring_distance = (r_inner + r_outer) / 2.0f;

    // [Alternative] Use outer boundary - commented out for comparison
    // float ring_distance = r_outer;  // Use outer boundary like RCAP


■ 영향 범위
--------------------------------------------------------------------------------
ring_distance 변수는 이후 sigma_y, sigma_z 계산에 모두 사용됨:

    float sigma_y = Sigma_h_Briggs_McElroy_Pooler_cpu(stab_class, ring_distance);
    float sigma_z = Sigma_z_Briggs_McElroy_Pooler_cpu(stab_class, ring_distance);

따라서 이 변경은 sigma_y와 sigma_z 계산 모두에 동일하게 적용됨.

[2] 현재 적용된 Sigma 보정 상세
================================================================================

■ Sigma_y 보정
--------------------------------------------------------------------------------
파일: gpuff_plot.cuh:1477-1479

적용된 보정:
    // σy 보정: Ft (샘플시간 보정인자)만 적용
    const float FT = 1.27f;  // Ft = (td/tref)^0.2 = (600/180)^0.2
    sigma_y = FT * sigma_y;

보정 인자 설명:
- Ft: 샘플시간 보정인자 (Sample Time Correction Factor)
- 공식: Ft = (td/tref)^0.2
  - td: 실제 샘플링 시간 = 600초
  - tref: 기준 샘플링 시간 = 180초 (Prairie Grass 실험 기준)
  - 지수 0.2: 경험적 상수
- 계산: (600/180)^0.2 = 3.333^0.2 ≈ 1.27

최종 공식:
    sigma_y_final = 1.27 × sigma_y_briggs

참고 - 제거된 보정:
- 이전에는 초기값 20m가 적용되어 있었음: sigma_y = 20 + 1.27 × sigma_y_briggs
- 사용자 요청에 따라 초기값 20m는 제거하고 Ft만 유지함


■ Sigma_z 보정
--------------------------------------------------------------------------------
파일: gpuff_plot.cuh:1481-1486

적용된 보정:
    // σz 상한값 적용: σz_max = mixing_height / sqrt(2π)
    // mixing height 내에서 균일 혼합 가정
    const float SQRT_2PI = 2.506628f;
    const float MIXING_HEIGHT = 1000.0f;  // mixing height (m)
    float sigma_z_max = MIXING_HEIGHT / SQRT_2PI;
    sigma_z = fminf(sigma_z, sigma_z_max);

상한값 계산:
- 공식: σz_max = H / √(2π)
  - H: 혼합층 높이 (Mixing Height) = 1000m
  - √(2π) ≈ 2.506628
- 계산: 1000 / 2.506628 ≈ 398.94m

물리적 의미:
- 혼합층 높이 이상으로 오염물질이 확산되지 않음
- 혼합층 내에서 균일 혼합(well-mixed) 가정 시의 유효 σz 상한

최종 공식:
    sigma_z_final = min(sigma_z_briggs, 398.94)

참고 - 미적용 보정:
- sigma_z에 대한 초기값은 적용되지 않음
- 표면거칠기 보정(Fsr)은 미적용
- 이로 인해 안정도 E, F에서 짧은 거리 불일치 발생 (아래 [3] 참조)


■ 최소값 보정 (공통)
--------------------------------------------------------------------------------
파일: gpuff_plot.cuh:1488-1489

    // Ensure minimum values
    sigma_y = fmaxf(sigma_y, 0.1f);
    sigma_z = fmaxf(sigma_z, 0.1f);

수치적 안정성을 위해 sigma 값이 0.1m 미만이 되지 않도록 함.

■ 관찰된 패턴
--------------------------------------------------------------------------------
1. 안정도가 높을수록(E, F) 짧은 거리에서 불일치가 큼
   - A, B class: Gpuff가 오히려 약간 높음
   - E, F class: Gpuff가 상당히 낮음 (최대 약 3배 차이)

2. 거리가 멀어질수록 Ratio가 1.0에 수렴
   - 약 2~3km 이상에서는 거의 일치

3. RCAP_sz - Gpuff_sz 절대 차이가 거리에 따라 감소

4. 안정도 A, B에서는 오히려 Gpuff가 약간 높게 나옴
   - 이는 Ft=1.27 보정이 sigma_y에 적용되어 있기 때문일 수 있음


■ 추정 원인
--------------------------------------------------------------------------------
1. Sigma_z 초기값 미적용
   - RCAP에서 sigma_y에 적용되는 것처럼 sigma_z에도 초기값(sigma_z_init)이
     적용될 가능성이 있음
   - 이 초기값이 짧은 거리에서 차이를 만들고, 먼 거리에서는 상대적으로
     영향이 작아져서 수렴하는 패턴 설명 가능

2. Virtual Source 개념
   - RCAP이 virtual source 개념을 적용하여 σz를 계산할 가능성
   - Release height에서의 초기 확산 폭을 고려하는 방식
   - 공식: σz_effective = √(σz_init² + σz_briggs²)

3. Release Height 관련 보정
   - 방출 높이(Release Height)에 따른 추가 보정이 있을 수 있음
   - 높은 방출 높이에서는 초기 수직 확산이 더 클 수 있음

4. 표면거칠기 보정 (Fsr)
   - sigma_y에 적용되는 표면거칠기 보정이 sigma_z에도 적용될 가능성

■ 모델 공식
--------------------------------------------------------------------------------
Sigma_y: σy = coefficient0 × x × (1 + coefficient1 × x)^coefficient2
Sigma_z: σz = coefficient0 × x × (1 + coefficient1 × x)^coefficient2

여기서 x는 풍하 거리(downwind distance, 단위: m)

-----   -----    ------    ------    ----
A       0.20     0.0       1.0       매우 불안정 (선형 증가)
B       0.12     0.0       1.0       불안정 (선형 증가)

================================================================================
[5] RCAP Ground Reflection Model
================================================================================

■ 모델 개요
--------------------------------------------------------------------------------
RCAP 모델설명서 식 3.2.4, 3.2.5에 따른 지면/역전층 반사 모델이 구현되어 있음.

파일: gpuff_plot.cuh:1492-1530

기본 개념:
    g = g1 + g2 + g3

여기서:
- g1: 반사 없는 수직확산항
- g2: 지면반사에 의한 수직확산항
- g3: 다중반사(역전층)에 의한 수직확산항


■ 상세 공식
--------------------------------------------------------------------------------
[g1: 반사 없는 수직확산항]
    g1 = exp[-(z-H)² / (2σz²)]

    - z: 계산 높이 (지표면에서 z=0)
    - H: 유효 방출 높이 (Effective Release Height)
    - σz: 수직 확산계수

[g2: 지면반사에 의한 수직확산항]
    g2 = exp[-(z+H)² / (2σz²)]

    - 지면(z=0)에서 거울상 반사를 고려

[g3: 다중반사(역전층)에 의한 수직확산항]
    g3 = Σ(n=1 to N) {
        exp[-((2nL-H)-z)² / (2σz²)] +
        exp[-((2nL-H)+z)² / (2σz²)] +
        exp[-((2nL+H)-z)² / (2σz²)] +
        exp[-((2nL+H)+z)² / (2σz²)]
    }

    - L: 역전층 높이 (Mixing Height) = 1000m
    - N: 반사 횟수 (기본값 5회)
    - 역전층과 지면 사이의 다중 반사 고려


■ 구현 상태
--------------------------------------------------------------------------------
현재 코드에서 N=5 (5회 반사)까지 계산하여 g 값을 산출하고,
이를 농도 계산에 적용하고 있음.

[7] 향후 검토 및 개선 필요 사항
================================================================================

■ 우선순위 높음
--------------------------------------------------------------------------------
1. RCAP sigma_z 계산 방식 확인
   - sigma_z에 초기값(sigma_z_init)이 적용되는지 확인
   - Virtual source 개념 적용 여부 확인
   - Release height 관련 보정 존재 여부 확인
   → RCAP 소스코드 또는 상세 기술문서 참조 필요

2. 거리 기준점 정확한 확인
   - RCAP이 ring 중앙점 vs outer boundary 중 어떤 것을 사용하는지
   - 이번에 중앙점으로 변경했으나, 정확한 확인 필요


■ 우선순위 중간
--------------------------------------------------------------------------------
3. 표면거칠기 보정 (ZSCALE) 검토
   - sigma_z에 표면거칠기 보정이 적용되는지 확인
   - 공식: ZSCALE = (z₀ / z₀,ref)^q = (z₀ / 3cm)^0.2

4. Plume Rise 효과 검토
   - 거리에 따른 plume height 변화가 sigma에 미치는 영향


■ 우선순위 낮음
--------------------------------------------------------------------------------
5. Virtual Source 구현 검토
   - 안정도 class 변경 시 연속성 유지
   - 공식: x_zj = (σ_zi / c_j)^(1/d_j)

6. Deposition에 의한 Q 감소 반영
   - RCAP에서는 거리에 따라 Local Source Inventory가 감소
   - 현재 Gpuff는 Q를 고정값으로 사용
