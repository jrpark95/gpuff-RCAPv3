[1] 검증 대상 메트릭 확장 (3개 → 6개)
================================================================================

■ 배경
--------------------------------------------------------------------------------
2025-12-01 작업에서는 3가지 메트릭(Center Air Conc., Sigma_y, Sigma_z)만
비교하였으나, RCAP 검증의 완전성을 위해 6가지 메트릭으로 확장함.


■ 확장된 메트릭 목록
--------------------------------------------------------------------------------
번호  메트릭명                   단위        설명
----  ----------                 ----        ----
1     Center Air Conc.           Bq-s/m³     중심선 공기 중 농도
2     Ground Air Conc.           Bq-s/m³     지표면 공기 중 농도 (z=0)
3     Center Ground Conc.        Bq/m²       지표면 침적 농도
4     X/Q                        s/m³        희석계수 (Dilution Factor)
5     Sigma-y                    m           수평 확산계수
6     Sigma-z                    m           수직 확산계수


■ 물리적 의미
--------------------------------------------------------------------------------
[Center Air Conc. vs Ground Air Conc.]
- Center Air Conc.: 플룸 중심선(방출 높이)에서의 공기 중 농도
- Ground Air Conc.: 지표면(z=0)에서의 공기 중 농도
- 관계: 지면반사 모델(g1+g2+g3)이 적용되어 z에 따라 달라짐

[Center Ground Conc.]
- 지표면 침적 농도 = Ground Air Conc. × 평균침적속도(avg_vdep)
- 입자 크기 분포에 따른 가중평균 침적속도 사용

[X/Q]
- 희석계수: 농도/방출률 비율
- 단위 방출률당 농도를 나타내며 방출량에 독립적인 지표


================================================================================
[2] Center Ground Conc. 계산식 수정
================================================================================

■ 문제점
--------------------------------------------------------------------------------
기존 구현에서 Center Ground Conc. 계산이 RCAP 방식과 달랐음.

[기존 방식 - 오류]
    ground_conc = ground_air * vd * dt

[RCAP 방식 - 정확]
    ground_conc = ground_air * avg_vdep


■ 수정 내용
--------------------------------------------------------------------------------
파일: gpuff_kernels_puff.cuh
함수: move_puffs_by_wind_RCAP3()

avg_vdep 계산 방식:
    - 추적 핵종의 chemical group 확인
    - 해당 chemical group의 입자 크기 분포(particle size distribution) 조회
    - 각 입자 크기별 침적속도(Vdepo)와 질량분율의 가중평균 계산

[추가된 코드]
    // Ground concentration using avg_vdep from particle size distribution
    NuclideData nuclide = d_ND[tracking_nuclide];
    int group = nuclide.chemical_group;
    float avg_vdep = 0.0f;
    if (group >= 1 && group <= ELEMENT_COUNT) {
        for (int size_idx = 0; size_idx < PARTICLE_COUNT; ++size_idx) {
            float fraction = d_particleSizeDistr[puff.unitidx * (ELEMENT_COUNT * PARTICLE_COUNT)
                                                + (group - 1) * PARTICLE_COUNT + size_idx];
            float vdep = d_Vdepo[size_idx];
            avg_vdep += fraction * vdep;
        }
    }
    float ground_conc = ground_air * avg_vdep;


■ 커널 파라미터 변경
--------------------------------------------------------------------------------
파일: gpuff_func.cuh

추가된 파라미터:
    - d_Vdepo: 입자 크기별 침적속도 배열
    - d_particleSizeDistr: 입자 크기 분포 배열
    - d_ND: 핵종 데이터 배열

[변경된 커널 호출]
    move_puffs_by_wind_RCAP3 << <blocks, threads_per_block >> >
        (d_puffs_RCAP, d_radius, SC.numRad, SC.numTheta,
         d_max_center_air_conc, d_max_ground_air_conc, d_max_ground_conc, d_max_xq,
         d_max_sigma_y, d_max_sigma_z,
         d_max_dir_center_air, d_max_dir_ground_air, d_max_dir_ground, d_max_dir_xq,
         d_max_tracking_nuclide,
         d_Vdepo, d_particleSizeDistr, d_ND);

■ 대기안정도 자동 파싱 기능
--------------------------------------------------------------------------------
Test.inp 파일에서 대기안정도를 자동으로 읽어와 결과 파일명에 반영.

[파싱 규칙]
    - RT350 라인 검색
    - RT350 다음 두 번째 값(인덱스 2)이 안정도 클래스
    - 유효값: A, B, C, D, E, F

[구현 코드]
    def parse_stability_from_test_inp(filepath):
        """Test.inp에서 RT350 라인의 stability 값 읽기 (두 번째 값)"""
        with open(filepath, 'r', encoding='utf-8') as f:
            for line in f:
                parts = line.split()
                if parts and parts[0] == 'RT350':
                    if len(parts) >= 3:
                        stability = parts[2].upper()
                        if stability in ['A', 'B', 'C', 'D', 'E', 'F']:
                            return stability
                        else:
                            raise ValueError(f"Invalid stability value '{stability}'")
                    else:
                        raise ValueError(f"RT350 line has insufficient values")
        raise ValueError(f"RT350 line not found in {filepath}")

[오류 처리]
    - RT350 라인이 없으면 ValueError 발생
    - 유효하지 않은 안정도 값이면 ValueError 발생

    - 터미널 출력과 동일한 내용

■ 시각화 옵션
--------------------------------------------------------------------------------
[Option 1: Original - 거리 vs 값]
    - X축: Distance (km), log scale
    - Y축: 메트릭 값, log scale
    - RCAP: 점선(--), Gpuff: 마커(o, s, ^, D, v, p)
    - 범례: 왼쪽 열 RCAP A~F, 오른쪽 열 Gpuff A~F

[Option 2: 1:1 Scatter - RCAP vs Gpuff]
    - X축: RCAP 값, Y축: Gpuff 값
    - 대각선(y=x): 완벽한 일치 기준선
    - 대각선 위: Gpuff > RCAP
    - 대각선 아래: Gpuff < RCAP

[Option 3: Ratio Plot - 비율 분석]
    - X축: Distance (km)
    - Y축: Gpuff/RCAP 비율
    - y=1 기준선: 완벽한 일치
    - 편차 패턴 분석에 유용

[Option 4: Stability-wise Subplots - 안정도별 분리]
    - 2×3 패널 레이아웃
    - 각 패널: 개별 안정도 클래스
    - 세부 비교에 유용

[Option 5: All Options]
    - 위 4가지 옵션 모두 생성
    - summary 폴더에 종합 그래프 추가

■ 범례 정렬 개선
--------------------------------------------------------------------------------
Option 1에서 범례를 RCAP/Gpuff로 그룹화하여 가독성 향상.

[기존]
    RCAP A, Gpuff A, RCAP B, Gpuff B, ...  (교차 배열)

[개선]
    왼쪽 열: RCAP A, RCAP B, RCAP C, RCAP D, RCAP E, RCAP F
    오른쪽 열: Gpuff A, Gpuff B, Gpuff C, Gpuff D, Gpuff E, Gpuff F

구현 방식:
    - RCAP 전체를 먼저 플롯 (범례 왼쪽 열 차지)
    - Gpuff 전체를 다음에 플롯 (범례 오른쪽 열 차지)
    - ncol=2 옵션으로 2열 범례 생성

- Gpuff/RCAP 비율: 1.05~1.20 범위
- Gpuff가 약간 높게 계산되는 경향
- sigma 차이가 농도에 반영된 결과

■ Ground Air Conc. 비교 결과
--------------------------------------------------------------------------------
- 근거리: 양호한 일치 (비율 1.0~1.3)
- 원거리 (> 10km): E, F 클래스에서 편차 증가
- 지면반사 모델(g1+g2+g3) 적용 확인

■ Center Ground Conc. 비교 결과
--------------------------------------------------------------------------------
- avg_vdep 적용 후 Ground Air Conc.와 동일한 패턴
- 침적속도 계산 방식 일치 확인

■ X/Q 비교 결과

- 농도 결과와 동일한 패턴 (단위 방출률 기준)
- 방출량 독립적 지표로서 검증에 유용
