RCAP sigma_z 불일치 문제 분석 요청

============================================================
상황 설명
============================================================
Gpuff(GPU 기반 대기확산 코드)와 RCAP의 결과를 비교하고 있습니다.
두 코드 모두 Briggs-McElroy-Pooler 확산 모델을 사용합니다.

문제:
- Center Air Concentration(농도)은 두 코드가 거의 동일하게 계산됨
- sigma_y도 초기값(20m)과 샘플시간 보정(Ft=1.27) 적용 후 잘 맞음
- 그러나 sigma_z는 짧은 거리에서 Gpuff가 RCAP보다 상당히 낮게 나옴
- 특히 안정도 E, F class에서 차이가 큼

현재 Gpuff에 적용된 보정:
- sigma_y: sigma_y_corrected = sigma_y_init(20m) + Ft(1.27) * sigma_y_briggs
- sigma_z: sigma_z_max = mixing_height / sqrt(2*pi) 상한값만 적용
- sigma_z 초기값이나 다른 보정은 미적용

============================================================
시뮬레이션 조건
============================================================
- Release Height: 500m
- Mixing Height: 1000m
- Sample Time: 600초
- Terrain: Rural
- Dispersion Model: Briggs-McElroy-Pooler

관찰된 패턴
============================================================
1. 안정도가 높을수록(E, F) 짧은 거리에서 불일치가 큼
2. 거리가 멀어질수록 Ratio가 1에 수렴함
3. Stability A, B에서는 Gpuff가 오히려 약간 높음
4. RCAP_sz - Gpuff_sz 차이가 거리에 따라 감소함

============================================================
Gpuff에서 사용 중인 Briggs-McElroy-Pooler sigma_z 공식
============================================================
sigma_z = coefficient0 * x * (1 + coefficient1 * x)^coefficient2

질문
============================================================
RCAP 매뉴얼을 참고하여 다음을 확인해주세요:

1. RCAP의 sigma_z 계산에서 Briggs 공식 외에 추가로 적용되는 보정이 있는가?
   - sigma_y에 적용되는 것처럼 초기값(sigma_z_init)이 있는가?
   - 표면거칠기 보정(Fsr)이 sigma_z에도 적용되는가?
   - Release height 관련 보정이 있는가?

2. 안정도 E, F class에서 짧은 거리의 sigma_z가 크게 나오는 이유는?
   - Virtual source 개념이 적용되는가?
   - Plume rise 관련 보정이 있는가?

3. RCAP에서 sigma_z 계산 시 사용하는 정확한 공식은 무엇인가?

RCAP 모델설명서의 sigma_z 관련 섹션(특히 3.2장 대기확산 모델)을 참고하여
위 데이터의 불일치 원인을 설명해주세요.
